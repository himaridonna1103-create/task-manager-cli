# 原稿スタイルガイド

## 基本方針

### 文体
- 基本: ですます調（丁寧め）
- 例外: 引用、見出し、箇条書きの一部

### 敬語レベル
- 基本: 丁寧語中心
- 顧客・読者向け: 丁寧語＋やわらかい言い回し

## 表記ルール

### カタカナ
- 長音: 一般的な表記に準拠（例: 「サーバー」）
- 複合語の区切り: 詰めて書く（例: 「マーケティングキャンペーン」）

### 数字
- 全角 / 半角: 基本は半角
- 3桁区切り: 1,000
- 単位: 統一（例: 〇〇名）

### 英字・記号
- 日本語文章中の半角英字: 前後スペースなし可（例: 「AIを活用した」）
- 記号（！？）: 全角
- 引用符: 「」

## 用語統一

| 意味 | 標準表記 | 非推奨 |
|------|---------|--------|
| エンドユーザー | お客様 / 飼い主さま（文脈による） | お客さま、顧客、ユーザー |
| 人工知能 | AI | A.I.、エーアイ、人工知能 |
| ウェブ | Web | WEB、ウェブ、web |
| インターネット | インターネット | ネット、INTERNET |

## 禁則事項

### 使わない言葉
- 差別的表現
- 専門用語の無説明使用
- 動物・ペットの扱いを軽視する表現

### 使用注意
- 「絶対」「必ず」: 事実誤認リスクがあるため、根拠が明確なときのみ
- 「最大」「最強」「業界No.1」「唯一」: ファクトチェック対象・優良誤認リスクに注意
- 効果・時短を暗示する断定表現（例: 「効果が大きい」）: 根拠がない場合は「〜と言われています」等に弱める
- サービスが未確定・準備中の場合: 「構想段階」「変更の可能性があります」等の留保を明示する

## 数値・データの扱い

- 具体的な数値にはソースを明記
- 「約〇〇」「およそ〇〇」は許容、断定時はソース必須
- 統計出典がない体感値は「〜はず」「〜と考えられます」等で断定を避ける

## 引用ルール

- 引用は「」で明示
- 出典を明記（著者名、書籍名/サイト名、ページ/URL）

## 見出し・構造

- 見出しレベル: H1（タイトル）は1つ、H2・H3を適切に階層化
- 箇条書きの冒頭: 「-」で統一
- 段落の長さ: 3〜5文程度を目安

## 業界固有の注意点（動物系サロン向けコンテンツ）

- グルーミング・トリミング業界の専門用語は、初出時に軽く言い換えを添える
- 「AIで時短」「AI導入効果」等の主張は、景品表示法（優良誤認・有利誤認）を意識し、根拠のない断定を避ける
- サービス紹介記事では、料金・提供内容が未確定の場合は必ずその旨を明示する
