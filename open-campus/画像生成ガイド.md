# 画像生成ガイド（バーチャルオープンキャンパス用）

案内役キャラをAI生成のリアル画像に差し替えるためのガイドです。
生成した画像を `open-campus/chars/` フォルダに下記のファイル名で保存するだけで、
ページが自動でイラスト→リアル画像に切り替わります（コード編集は不要）。

## 保存ルール

| キャラ | ファイル名 | 内容 |
|--------|-----------|------|
| あかり | `chars/akari.png` | 案内役・女子学生（ラベンダースクラブ制服） |
| りく | `chars/riku.png` | 案内役・男子学生（ラベンダースクラブ制服） |
| マロン | `chars/maron.png` | 白いビションフリーゼ |
| みお先生 | `chars/mio.png` | トリマー担当の若い女性の先生 |
| 田中先生 | `chars/tanaka.png` | 教務・穏やかなベテラン男性 |
| 大地先生 | `chars/daichi.png` | トレーニング担当・熱血男性 |
| さくら先生 | `chars/sakura.png` | 動物看護担当・優しい若手女性 |

- **形式**: 背景透過PNG（必須。白背景のままだと四角い枠が見えてしまいます）
- **サイズ**: 横600px以上あればきれいに表示されます（縦長・全身）
- **切り抜き方法**: Canvaの背景リムーバー／PowerPointの「背景の削除」など。
  Canvaでの切り抜きはClaudeからもお手伝いできます

# 360度背景画像の生成ガイド

各エリアの背景（今は仮の室内イメージ）をAI生成の360度画像に差し替えるためのガイドです。
生成した画像を `open-campus/photos/` フォルダに下記のファイル名で保存するだけで、
次にページを開いた時に自動で切り替わります（コード編集は不要）。

## 保存ルール

| エリア | ファイル名 |
|--------|-----------|
| エントランス | `photos/entrance.jpg` |
| トリミング実習室 | `photos/grooming.jpg` |
| トレーニング実習室 | `photos/training.jpg` |
| 看護実習室 | `photos/nursing.jpg` |
| 教室（座学） | `photos/classroom.jpg` |
| フィナーレ | `photos/finale.jpg` |

- **形式**: JPGまたはPNG。**横:縦=2:1**（エクイレクタングラー形式）が理想
- **サイズ**: 横4096px前後がきれい。2048pxでも十分見られます
- 多少比率がずれていても自動で引き伸ばして表示します（極端だと歪みます）

## 生成ツールの選び方

1. **Skybox AI（Blockade Labs）── いちばんおすすめ**
   360度画像専用の生成AI。つなぎ目のない本物のエクイレクタングラー画像が出ます。
   プロンプトを入れて生成→エクスポートするだけ。英語プロンプト推奨
2. **Nano Banana（Gemini）/ GPT Image ── 手持ちのツールでOK**
   下のプロンプトで「360度パノラマ風」の画像が作れます。専用ツールではないので
   左右のつなぎ目が合わないことがありますが、プロトタイプには十分です

## 生成プロンプト（Nano Banana / Gemini用・日本語でOK）

共通の型：冒頭に必ずこれを付ける

```
360度パノラマ写真、エクイレクタングラー形式、横:縦=2:1の超横長画像。
水平線が画像の上下中央にあり、左端と右端が自然につながる構図。
人や動物は写っていない。明るい照明、清潔感のある空間、写実的な写真。
```

## 360度背景のコツ・注意

- 生成画像が2:1でない時は、Canva等で**2:1にトリミング**してから保存するときれい
- 「つなぎ目」が気になったら、その画像をNano Bananaに渡して
  「左端と右端が自然につながるように修正して」と編集依頼するのも手
- 実在の学校・施設の名前を入れないこと（あくまで架空の校内イメージ）
- 本物の360度写真（THETA等）が撮れたら、同じファイル名で上書きするだけで差し替え完了

## コツ・注意

- **一発で理想の画像は出ません**。数回生成して、いちばん「その人らしい」1枚を選ぶ
- **気に入った1枚は必ず保存**。今後ポーズ違い（指差し・お辞儀など）を作る時は、
  その画像をNano Bananaに渡して「この人物のまま、ポーズを〇〇に変えて」と編集すると顔が安定します
- マロンも同様に、気に入った1枚を基準にすると毎回同じ子になります
- ページには「案内役の先生・犬は架空のキャラクターです（画像はAI生成を含みます）」と
  常時表示済み。実在の先生と誤解されない設計にしています
- 実在の人物・有名人に似せる指示は入れないこと（肖像権）
