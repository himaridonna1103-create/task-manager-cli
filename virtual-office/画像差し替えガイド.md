# 画像差し替えガイド（ドット絵 → AI生成画像）

> **このガイドどおりにやれば、Sonnet や Haiku でも安全に差し替えできます。**
> コードのロジックは触りません。「画像を置く → 設定に1行足す」だけです。

## 仕組み

- 画像が設定されている箇所は**画像**が表示され、設定がない箇所は**ドット絵のまま**表示されます
- つまり「1匹だけ差し替え」「少しずつ差し替え」ができます。設定行を消せばドット絵に戻ります

## 差し替えの手順（コピペで使える指示例つき）

### ① キャラクター（ワンちゃん）を差し替える

1. 画像を `images/char/<メンバーID>.png` に置く（例：`images/char/morning.png`）
2. **story.html と office.html の両方**の `CHAR_IMAGES` に1行足す：

```js
const CHAR_IMAGES = {
  "morning": "images/char/morning.png",
};
```

**Sonnetへの指示例**：
「images/char/morning.png を置いたので、story.html と office.html の CHAR_IMAGES に "morning" の行を追加して。画像差し替えガイド.md の手順どおりに。」

### ② 部署カードの背景（story.html のみ）

1. 画像を `images/scene/<部署名>.png` に置く
2. `SCENE_IMAGES` に1行足す：`"秘書室": "images/scene/秘書室.png",`
3. ヒーローの建物は キー `"hero"`：`"hero": "images/hero.png",`

### ③ おしごと劇場の背景（story.html のみ）

1. 画像を `images/theater/<部署名>.png` に置く
2. `THEATER_IMAGES` に1行足す：`"秘書室": "images/theater/秘書室.png",`
   （文字が読めるよう、自動で暗めのフィルタがかかります）

### ④ 最後に必ず：公開版への同期

story.html を変えたら、開発メモ.md の「🔁 同期ルール」どおり
`demo-site/index.html` と `C:\Users\karim\portfolio\works\himari-company-office.html` にも反映する。
画像フォルダ `images/` も **demo-site と portfolio/works にコピーが必要**（相対パスのため）。

## 推奨サイズ・形式

| 用途 | サイズ目安 | 形式 |
|---|---|---|
| char（キャラ） | 512×512 | **背景透過PNG**（正方形・キャラ全身） |
| scene（部署背景） | 1200×400（横長3:1） | PNG/JPG |
| theater（劇場背景） | 1200×600（横長2:1） | PNG/JPG |
| hero（建物） | 1120×1000 | PNG/JPG |

## 画風をそろえるための基本プロンプト（画像生成AI用）

全キャラ共通のベース（これに犬種を足して使う）：

```
水彩絵本風のやさしいイラスト、温かい昼の光、
デフォルメされたかわいい犬のキャラクター、全身、正面向き、
首に小さなスカーフ、背景なし（透過）、柔らかい色彩、絵本の挿絵のような質感
```

例（morning＝柴犬）：
```
上記ベース ＋ 柴犬、赤茶色の毛、白いマズル、元気な表情、朝日のような明るい雰囲気
```

※犬種は story.html / office.html の `BREEDS` に全員分書いてあります（毛色つき）。
※プロンプトの細かい調整は image-prompt-generator スキルに頼むと早いです。

## 差し替え後の確認

1. プレビュー（launch.json の virtual-office サーバー）で開く
2. 画像が表示されない場合：パスの綴り・拡張子（.png/.jpg）・設定行の末尾カンマを確認
3. コンソールエラー0件・劇場を1本通しで再生して確認
