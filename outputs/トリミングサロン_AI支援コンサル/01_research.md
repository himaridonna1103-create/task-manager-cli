## 検索意図

「雑務に追われるトリミングサロンオーナーが、"AIで本当に楽になるのか・自分にもできるのか・誰に聞けば安心か" を確かめたい瞬間」。

- 情報収集段階（Know）が主。ツール購入直前（Buy）ではない
- 「AIは気になるが難しそう」という**期待と警戒が半々**の心理状態
- 比較検討ではなく「最初の一歩と、信頼できる案内人」を探している

## 顕在ニーズ

- 予約管理・カルテ記録・SNS投稿・請求書などの雑務を減らしたい
- AIが話題だが、何から始めればいいかわからない
- 難しい設定や高額なシステム導入は避けたい
- 施術・接客に集中できる時間を取り戻したい

## 潜在ニーズ（マズロー段階まで深掘り）

### 1. 「休みたい・体がもたない」【第1段階：生理的欲求】
雑務を減らしたい → なぜ？ → 営業後・休憩中まで事務作業で休めない → なぜつらい？ → 一人〜少人数経営では休憩すら削られ、プライベートが消える（サロン経営の悩み調査でも「時間のゆとりが無い」「休憩が取れない」が頻出）→ **睡眠・休息という生理的欲求が満たされていない**。

### 2. 「自分が倒れたら店が終わる」【第2段階：安全欲求】＝**主軸**
効率化したい → なぜ？ → 予約詰め込みで回す経営は消耗戦 → なぜ怖い？ → 小規模サロンは代わりがおらず、自分の体調・気力が尽きた時点で売上も廃業リスクに直結 → **経営と健康の持続＝経済的・身体的な安全欲求**。トリマー疲弊による廃業事例も業界メディアで語られている。

### 3. 「業界をわかってくれる人に頼りたい」【第3段階：社会的欲求】
AIは気になるが手を出せない → なぜ？ → IT用語がわからず、ベンダー営業は「現場を知らない」感じがして怖い → なぜ怖い？ → 犬の扱い・施術の流れ・カルテの中身を説明するところから始めるのは負担で、騙されそうな不安もある → **「同じ業界の言葉が通じる理解者・味方が欲しい」という帰属・つながりの欲求**。→ 本記事の差別化の核。

### 4. 「トリマーとして誇れる仕事をしたい」【第4〜5段階：承認・自己実現欲求】
雑務ゼロ化の先に何がある？ → 施術の質と接客に時間を使える → なぜそれが大事？ → 飼い主に「ここに任せてよかった」と言われるサロンでいたい、技術者としての自分を発揮したい → **承認欲求〜自己実現欲求**。記事のクロージング（未来像）で使う。

**主軸の段階**: 第2段階（安全欲求）を土台に、第3段階（業界理解者への信頼）で差別化する。

## 競合上位記事の共通点

調査した競合（予約システム比較・サロン集客ガイド・美容室AI活用・サロンコンサル）に共通する論点:

1. **ツール紹介・比較型が主流**: 予約システムの機能・初期費用・月額の一覧比較（24時間予約受付、ダブルブッキング防止、リマインド自動化）
2. **施策の羅列**: MEO・Instagram・LINE公式・口コミ管理の4チャネル整理
3. **効率化のメリット訴求**: 「事務作業を減らして本業（施術）に集中」という便益の言語化は各記事共通
4. **費用目安の提示**: 月額0円〜数万円のレンジ提示
5. **AI活用は隣接業界（美容室）の一般論**: ChatGPTでSNSキャプション生成・チャットボット予約対応など

## 競合上位記事の弱点

1. **「トリミングサロン×生成AI」の一次体験記事が実質不在**: 唯一見つかった事例記事（office-iolite）は404で消滅。市場に空白がある
2. **書き手が業界外**: システムベンダー・Web制作会社・マーケ会社が執筆しており、「施術中は手が濡れて携帯を触れない」「犬の状態記録は言語化が難しい」といった現場実感が無い
3. **ツール比較で止まり「使いこなすまで」が無い**: 導入後の挫折・設定の壁・続かない問題に触れた記事が無い（＝伴走支援の存在意義をそのまま示せる）
4. **感情面への寄り添いが無い**: 「AIは難しそう・怖い」という心理的ハードルを扱った記事が皆無。機能説明から始まる記事ばかり
5. **1日の業務フローに沿ったビフォーアフターが無い**: 「朝の予約確認〜施術〜カルテ〜SNS〜閉店後の事務」という時間軸での変化描写はどの記事にも無い
