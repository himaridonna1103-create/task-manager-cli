## 2. 中小企業のAI・生成AI導入率

### 中小企業基盤整備機構（中小機構）調査

- 出典：[中小企業基盤整備機構「中小企業のAI等の利活用に係る実態調査」（ポイント版）](https://www.smrj.go.jp/research_case/questionnaire/fbrion0000002pjw-att/202603_AI_point.pdf)
- 公表日：**2026年3月**

| 指標 | 数値 |
|---|---|
| AI導入率 | 20.4% |
| 導入検討中を含む前向き企業 | 39.0%（導入20.4% + 検討中18.6%） |
| AI導入企業のうち「生成AI」利用率 | **82.6%**（最も高い） |
| 導入目的トップ「業務効率化・作業時間短縮」 | 87.0% |
| 導入目的2位「品質向上」 | 32.3% |

**業務分野別のAI導入率**

| 分野 | 導入率 |
|---|---|
| 総務・管理部門 | 68.3% |
| 営業・販売・サービス部門 | 60.3% |
| 経営・企画部門 | 58.5% |
| 製造・生産部門 | 34.9% |

**業種別の活用推進率**

| 業種 | 推進率 |
|---|---|
| 情報通信業 | 64.4% |
| 金融・保険業 | 42.4% |
| サービス業他 | 38.5% |

**フェーズ別の主な課題**

| フェーズ | 最多の課題 |
|---|---|
| 導入検討以前 | 具体的な活用場面が不明 |
| 導入検討中 | 導入を推進する人材がいない |
| 導入後 | 社内ルール・方針整備が追い付かない |

### 別調査との数値差について

Web検索では、株式会社Leach「中小企業AI導入実態調査2026」で**導入率12%**という異なる数値も見つかりました（[PR TIMES](https://prtimes.jp/main/html/rd/p/000000045.000153035.html)、2026年公表）。中小機構調査（20.4%）との差は、調査対象企業の規模・業種構成や「導入」の定義の違いによるものと考えられます。

**【推測】** どちらが実態により近いかは、両調査のサンプル設計を精査しないと判断できません。SNSで引用する際は、出典を明記したうえで「調査によって差がある」旨を添えるのが安全です。

**活用メモ**：「生成AI利用率82.6%」「業務効率化目的87.0%」は、ひまりさんのサービス訴求（雑務ゼロ化）と直結する数字。「導入以前の最大の壁は"具体的な活用場面が不明"」は、投稿②③（教育系・共感系）の裏付けとして使いやすい。

## 3. 生成AI関連市場の構造

- 出典：[公正取引委員会「生成AIに関する実態調査報告書ver.2.0」](https://www.jftc.go.jp/houdou/pressrelease/2026/apr/260416_generativeai.html)
- 公表日：**2026年4月16日**

### 市場の3層構造

1. **インフラストラクチャーレイヤー**：生成AIモデルを構築・運用する環境（半導体・クラウド）
   - 半導体供給：NVIDIAが優位
   - クラウド：Amazon・Microsoft・Googleの3社が有力
2. **モデルレイヤー**：生成AIモデルを構築・提供
3. **アプリケーションレイヤー**：生成AIサービスを提供

- 前回報告書（ver.1.0、[2025年6月6日公表](https://www.jftc.go.jp/houdou/pressrelease/2025/jun/250606generativeai.html)）の内容を集約し、独占禁止法上の論点を再整理したもの

**【推測】** 各レイヤーの具体的な市場シェア・事業者数の詳細数値は、報告書本体（PDF）内に記載がある可能性がありますが、今回はPDFの機械的な読み取りができず未確認です。正確な数値引用が必要な場合は報告書原本の直接確認を推奨します。

**活用メモ**：「大手プラットフォーマーが上流を握る中、アプリケーション層（＝実際の業務活用）はまだ伸びしろがある」という文脈で、地方の小規模事業者にもチャンスがある、という論の補強に使える。

## 4. IT・DX人材不足の実態

### IPA（情報処理推進機構）「DX動向2024」

- 出典：[IPA「DX動向2024 - 深刻化するDXを推進する人材不足と課題」](https://www.ipa.go.jp/digital/chousa/discussion-paper/dx-talent-shortage.html)

| 指標 | 数値 |
|---|---|
| DX推進人材の「量」が大幅に不足していると回答した企業 | **62.1%**（2021年度30.6%から倍増） |

### 経済産業省「IT人材需給に関する調査」

| 指標 | 数値 |
|---|---|
| 2030年のIT人材不足予測（高位シナリオ） | 約**79万人** |

- 出典：経済産業省「IT人材需給に関する調査」（2019年公表）※IPA資料経由で引用確認
- **【推測】** この79万人という数字は2019年時点の試算であり、2026年現在の状況を反映した最新推計ではない可能性があります。引用時は「2019年時点の経産省試算」と明記するのが安全です。

**活用メモ**：「DXを推進する人材不足は2年で倍増」という変化率は、危機感を伝える投稿（②の問題提起系）に使える。ただし79万人の数字は少し古いので、使う場合は年度を必ず明記する。

## 5. 経営課題における人材強化の重要性

- 出典：[帝国データバンク「企業の経営課題に関するアンケート（2026年）」](https://www.tdb.co.jp/report/economic/20260304-management-issues/)
- 公表日：**2026年3月4日**
- 調査概要：経営者・管理者対象、有効回答5,241社、31の経営課題を5カテゴリで調査

| 経営課題 | 回答率 |
|---|---|
| 人材強化（採用・定着・育成） | **90.2%**（最多） |
| 既存顧客との関係深耕 | 66.0% |
| 販路開拓 | 60.5% |

**企業規模別の「人材強化」回答率**

| 規模 | 回答率 |
|---|---|
| 大企業 | 98.2% |
| 中堅企業 | 96.6% |
| 中小企業 | 94.0% |
| 小規模企業 | 77.6% |

**活用メモ**：小規模企業でも77.6%が人材強化を課題に挙げている＝「人を増やせないなら、AIで雑務を減らす」という提案の説得材料になる。企業規模が小さいほど回答率が下がる傾向はあるが、それでも8割弱が課題視している点は強調価値あり。

## 6. 中小企業庁のAI導入支援策

- 出典：[中小企業庁「デジタル化・AI導入補助金2026」概要](https://www.chusho.meti.go.jp/koukai/yosan/r8/digital_ai_summary.pdf)
- 公表日：**令和8年4月（2026年4月）**

| 項目 | 内容 |
|---|---|
| 補助率 | 1/2〜2/3 |
| 補助上限額 | 最大450万円（取り組むプロセス数に応じる） |
| 対象経費 | ソフトウェア購入費・クラウド利用料（最大2年分）、**導入コンサルティング費**、研修費 |

### 無料サポート体制（中小機構）

- 「IT経営サポートセンター」：無料相談窓口
- 「IT化支援アドバイザー」：無料で3回訪問、課題整理・ツール比較検討を支援
- 複数の中小・小規模事業者が連携してITツールを導入する「地域DX」の取組も支援対象

**【推測】** 上記の補助金・無料サポートが、ひまりさんのコンサル業務（有償）とどう役割分担・併用できるかは未検証です。競合というより「無料相談で気づいた課題を、伴走支援で解決する」という補完関係になり得るという仮説であり、確認が必要です。

**活用メモ**：「補助金の対象経費に"導入コンサルティング費"が含まれる」という事実は、見込み客の心理的ハードル（費用面）を下げる材料として投稿⑤（告知系）に使える可能性がある。ただし補助金の対象要件は複雑なため、断定的な訴求は避け「対象になる場合がある」程度の紹介に留めるのが安全。

## 7. SNS投稿への活用アイデア

| データ | 使えそうな投稿タイプ | ポイント |
|---|---|---|
| 国内生成AI市場が7年で約15倍 | 発表系・教育系 | 「今が波に乗るタイミング」の根拠に |
| 生成AI利用率82.6%（AI導入企業のうち） | 共感系・教育系 | 「もう導入企業の8割が使っている」という後押し |
| 導入以前の最大課題「具体的な活用場面が不明」 | 共感系・質問系 | 投稿②③の悩み提起の裏付けに |
| 人材強化が経営課題1位（90.2%、小規模でも77.6%） | 共感系 | 「人を増やせないなら」という文脈の補強 |
| DX人材「量」不足62.1%（2年で倍増） | 問題提起系 | 危機感の演出（ただし出典年は明記） |
| 補助金対象に導入コンサル費が含まれる | 告知系 | 費用面のハードルを下げる（断定は避ける） |
