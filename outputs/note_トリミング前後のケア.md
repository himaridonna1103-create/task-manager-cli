# トリミングのあと、うちの子が元気ない…それ、実はよくあることなんです

こんにちは、ひまりです。
動物系専門学校でグルーミングを教えながら、現場でもたくさんのわんちゃん・ねこちゃんと関わってきました。

今日は、飼主さんからよくいただく相談のひとつ「トリミングのあと、なんだか元気がない」「体を痒がっている」について、現場目線でお話ししたいと思います。

## トリミング後に「様子が変」と感じたら

トリミングを終えて帰ってきた子が、ぐったりしていたり、体を気にして舐めていたり、いつもよりおとなしかったり——そんな姿を見ると、飼主さんはとても心配になりますよね。

実はこれ、多くの場合は「病気」ではなく「疲れ」や「刺激への反応」であることがほとんどです。

トリミングは、シャンプー・ブロー・カット・爪切り・耳掃除など、短時間にたくさんの作業が詰め込まれています。人間で言えば、美容院と健康診断を一気にやるようなもの。わんちゃんにとっては相当な体力と気力を使う一大イベントなんです。

## 帰宅後に見られやすい様子と、その理由

- **ぐったり眠る** → 緊張と体力消耗によるもの。数時間〜半日ほどで落ち着くことが多いです。
- **体を痒がる・気にする** → 毛を刈った直後は皮膚が空気に触れて敏感になっていたり、シャンプーの匂いに違和感を覚えていることが多いです。
- **食欲が少し落ちる** → 緊張状態が続いた反動で、一時的に食が細くなることがあります。

もちろん、赤みや発疹、明らかな痛がり方、丸1日以上続く元気のなさなどがあれば、それは別の話。迷わずサロンまたは動物病院にご相談くださいね。

## 飼主さんにできる、帰宅後のちょっとしたケア

1. **すぐに構いすぎない**
   愛情から声をかけたくなる気持ち、すごくよくわかります。でも、まずは静かな場所でゆっくり休ませてあげるのが一番です。

2. **体を触って様子を見る（ただし優しく）**
   赤みや傷、腫れがないか、普段のスキンシップの延長で軽く確認してあげてください。

3. **水分補給を忘れずに**
   施術中は緊張で水を飲めていないことも多いです。新鮮なお水を用意してあげましょう。

4. **当日〜翌日は激しい運動を避ける**
   カット直後の肌はデリケートです。長時間のお散歩やドッグランは1日置いてからがおすすめです。

## 最後に

トリミングは「きれいにする時間」であると同時に、わんちゃんにとっては「頑張った時間」でもあります。
帰ってきたときの様子は、その子なりの「今日は疲れたよ」のサインだと思って、優しく受け止めてあげてください。

気になることがあれば、遠慮なく担当のトリマーに聞いてみてくださいね。現場を知っているからこそ伝えられることが、きっとまだまだあります。
